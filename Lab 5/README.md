Текст задачи: Составить программу, которая формирует список L, включив в него по одному разу элементы, которые входят в один из списков L1 и L2, но в то же время не входят в другой из них.

Алгоритм решения: Созданы два исходных списка `l1` и `l2`. Итоговый список `result` создается как `ArrayList` (так как он будет изменяться, в отличие от исходных `List.of`). Алгоритм использует два последовательных цикла. В первом цикле перебираются элементы `l1`; если элемента нет в `l2` и его еще нет в `result`, он добавляется в итоговый список. Во втором цикле аналогично перебираются элементы `l2` с проверкой на отсутствие в `l1`. Проверка `!result.contains(item)` предотвращает появление дубликатов в результирующем списке.

##### Задача 5. Звонкие согласные более чем в одном слове

Текст задачи: Файл содержит текст на русском языке. Напечатать в алфавитном порядке все звонкие согласные буквы, которые входят более чем в одно слово.

Алгоритм решения: 

Исходный текст приводится к нижнему регистру и разбивается на массив слов с помощью регулярного выражения `split("[^а-яё]+")`, которое отсекает все не-буквы. Задается множество звонких согласных `voicedConsonants`. Для подсчета слов используются два `Set`: `seenLetters` (буквы, встречавшиеся ранее) и `result` (искомые буквы). Создан `result` типа `TreeSet`, который автоматически сортирует элементы по алфавиту. Для каждого слова создается промежуточное множество `wordLetters`, чтобы одинаковые буквы внутри одного слова не учитывались дважды. Если звонкая буква из слова уже присутствует в `seenLetters`, она добавляется в `result`; иначе она помещается в `seenLetters`.

#### Задание 6. Очередь 

##### Задача 1

Текст задачи: Напечатать в обратном порядке элементы непустой очереди L.

Алгоритм решения: 

Создается очередь `Queue<String>` на базе `LinkedList` и заполняется элементами. Поскольку очередь работает по принципу FIFO и не поддерживает доступ по индексу, создается пустой список `ArrayList`. С помощью цикла `while` и метода `queue.poll()` все элементы извлекаются из очереди (очередь при этом очищается) и последовательно добавляются в список. После этого элементы списка выводятся на экран в обратном порядке с помощью цикла `for`, который начинается с `list.size() - 1` и идет до `0`.

Для создания объекта `Polyline` используется `Collectors.collectingAndThen`, который сначала собирает точки в `List`, а затем передает этот список в конструктор `Polyline`.

##### Задача 2

Текст задачи: Дан	текстовый	файл	со	строками,	содержащими	имя	человека	и	его	номер	в	следующей	форме:	
Вася:5	
Петя:3	
Аня:5	
Номера	людей	могут	повторяться.	У	каких-то	людей	может	не	быть	номера.	
Необходимо	написать	стрим	выполняющую	следующее:	
читаются	все	люди	из	файла,	все	имена	приводится	к	нижнему	регистру,	но	с	первой	буквой	в	
верхнем	регистре,	убираем	из	перечня	всех	людей	без	номеров,	а	имена	оставшихся	группируются	
по	их	номеру:	
[5:[Вася,	Аня],	3:[Петя]]

Алгоритм решения: 

Файл читается с помощью `Files.lines(Path)`, который сразу возвращает `Stream<String>` (используется конструкция try-with-resources для закрытия потока). С помощью `filter(line -> line.contains(":"))` убираются строки без номеров. В методе `map` строка разбивается по двоеточию, имя форматируется (первая буква в верхнем регистре, остальные в нижнем), и возвращается пара `Map.entry(name, number)`. Терминальная операция `Collectors.groupingBy` группирует элементы. Ключом группы становится номер (`entry.getValue()`). С помощью вложенного коллектора `Collectors.mapping` из каждой пары извлекается только имя (`entry.getKey()`) и собирается в список `Collectors.toList()`.
