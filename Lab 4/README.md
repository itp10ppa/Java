#### Задание 1. Обобщенные типы. Типовые переменные, <>

##### Задача 1. Обобщенная коробка

Текст задачи: 
Создайте сущность Коробка, которая обладает следующими характеристиками: может хранить один произвольный объект в один момент времени; объект можно получить и разместить на хранение в любой момент времени; если объект забирают из коробки – ссылку на этот объект необходимо обнулить; если объект кладут в коробку, но она не пуста – необходимо выкинуть исключение; имеет метод проверки на заполненность; методы класса должны работать с тем типом данных, который был указан во время создания объекта. Создайте Коробку, которая может хранить целочисленное значение, разместите туда число 3. Передайте Коробку в какой-либо метод, извлеките значение и выведите его на экран.

Алгоритм решения: 
Класс Box<T> содержит одно поле T item. Конструктор без параметров оставляет поле равным null, поэтому коробка создаётся пустой. Метод setItem проверяет isEmpty(): если коробка пуста – значение присваивается полю, иначе выбрасывается IllegalArgumentException. Метод getItem сохраняет текущее значение в локальную переменную, обнуляет поле и возвращает сохранённое значение, что обеспечивает требование об обнулении ссылки при извлечении. Метод isEmpty возвращает item == null. В главном методе создаётся пустая коробка Box<Integer>, в неё кладётся число 3, затем коробка передаётся в статический обобщённый метод method11, который извлекает значение и выводит его на экран.

##### Задача 2. Без null

Текст задачи: 
Создайте сущность Хранилище, которая обладает следующими характеристиками: может хранить один произвольный объект в один момент времени; хранилище неизменяемо; объект кладется в Хранилище при его создании, в качестве объекта может быть сохранено также и значение null; хранилище может вернуть ссылку на Объект; если вместо объекта хранится null, необходимо вернуть какое-либо альтернативное значение; метод получения значения должен работать с тем типом данных, который был указан во время создания объекта. Выполните следующие задания: создайте Хранилище чисел, положите туда значение null, передайте Хранилище в какой-либо метод, извлеките значение и выведите его на экран, альтернативой должно быть число 0; создайте Хранилище чисел, положите туда значение 99, передайте Хранилище в какой-либо метод, извлеките значение и выведите его на экран, альтернативой должно быть число -1; создайте Хранилище строк, положите туда значение null, передайте Хранилище в какой-либо метод, извлеките значение и выведите его на экран, альтернативой должна быть строка "default"; создайте Хранилище строк, положите туда значение "hello", передайте Хранилище в какой-либо метод, извлеките значение и выведите его на экран, альтернативой должна быть строка "hello world".

Алгоритм решения: 
Класс Storage<T> содержит два приватных final-поля: value и altValue. Оба поля задаются в конструкторе, поэтому хранилище неизменяемо (сеттеров нет, поля final). Метод getValue проверяет, равно ли value значению null: если да – возвращает altValue, иначе возвращает value. В главном методе создаются четыре хранилища под четыре сценария (числа с null и альтернативой 0, числа со значением 99 и альтернативой -1, строки с null и альтернативой "default", строки со значением "hello" и альтернативой "hello world"); каждое передаётся в статический обобщённый метод method12, который извлекает значение через getValue и выводит его на экран.

#### Задание 2. Параметризации. Маски типов и их ограничения

##### Задача 3. Начало отсчета

Текст задачи: 
Создайте метод, принимающий Коробку из задачи 3.1.1, и кладет в неё трехмерную точку координат (из задачи 2.1.5) с произвольными значениями. Метод должен позволять передавать Коробку с более чем одним видом параметризации.

Алгоритм решения: 
Используется класс Box<T> из задачи 3.1.1 и классы Point и Point3D из задачи 2.3.5 (Point3D наследуется от Point). Метод method23 принимает параметр типа Box<? super Point3D> – маска с нижней границей, которая допускает передачу коробок с параметризацией Point3D, Point, Object и любым предком Point3D. Внутри метода создаётся объект Point3D с произвольными координатами, который кладётся в коробку через setItem (коробка должна быть пустой, иначе будет выброшено исключение), после чего значение извлекается через getItem и выводится на экран. В главном методе создаются две пустые коробки с разной параметризацией – Box<Point3D> и Box<Point>, обе передаются в method23, что демонстрирует работу маски с более чем одним видом параметризации.

#### Задание 3. Обобщенные методы. Автовывод типа

##### Задача 1. Функция

Текст задачи: 
Разработайте такой метод, который будет принимать список значений типа T и объект, имеющий единственный метод apply. Данный метод надо применить к каждому элементу списка и вернуть новый список значений типа P, при этом типы T и P могут совпадать, а могут не совпадать. Используйте разработанный метод следующим образом: 1) передайте в метод список со значениями "qwerty", "asdfg", "zx", а получите список чисел, где каждое число соответствует длине каждой строки; 2) передайте в метод список со значениями 1, -3, 7, а получите список, в котором все отрицательные числа стали положительными, а положительные остались без изменений; 3) передайте в метод список, состоящий из массивов целых чисел, а получите список, в котором будут только максимальные значения каждого из исходных массивов.

Алгоритм решения: 
Объявлен функциональный интерфейс Function<T, P> с единственным методом P apply(T t). Разработан обобщённый метод apply с двумя параметрами типа: static <T, P> List<P> apply(List<T> list, Function<T, P> func). Метод создаёт новый ArrayList<P>, проходит по исходному списку и для каждого элемента вызывает func.apply(элемент), добавляя результат в новый список, после чего возвращает его. Созданы три класса-реализации интерфейса: StringLength (возвращает длину строки), AbsNumbers (возвращает модуль числа через Math.abs), MaxArray (находит максимум в массиве циклом, начиная с первого элемента). В главном методе метод apply вызывается трижды с разными списками и объектами-реализациями; параметры типа не указываются явно – компилятор выводит их автоматически из аргументов (автовывод типа).

##### Задача 2. Фильтр

Текст задачи: 
Разработайте такой метод, который будет принимать список значений типа T и объект, имеющий единственный метод test (принимает T и возвращает boolean). Верните новый список типа T, из которого удалены все значения, не прошедшие проверку условием. Используйте разработанный метод следующим образом: 1) передайте в метод список со значениями "qwerty", "asdfg", "zx" и отфильтруйте все строки, имеющие менее трех символов; 2) передайте в метод список со значениями 1, -3, 7 и отфильтруйте все положительные элементы; 3) передайте в метод список, состоящий из массивов целых чисел, а получите список, в котором будут только те массивы, в которых нет ни одного положительного элемента.

Алгоритм решения: 
Объявлен функциональный интерфейс Function2<T> с единственным методом boolean test(T t). Разработан обобщённый метод test с одним параметром типа: static <T> List<T> test(List<T> list, Function2<T> func). Метод создаёт новый ArrayList<T>, проходит по исходному списку и добавляет элемент в новый список только в том случае, если func.test(элемент) вернул true; остальные элементы пропускаются. В отличие от задачи 3.3.1 тип элементов не меняется, поэтому используется один параметр типа. Созданы три класса-реализации: LengthFilter (проверяет, что длина строки не меньше 3), PositiveFilter (проверяет, что число больше 0), NegativeFilter (проходит по массиву и возвращает false при обнаружении положительного элемента, иначе true – то есть массив не содержит положительных чисел). В главном методе метод test вызывается трижды с разными списками и фильтрами; результат третьего сценария выводится поэлементно через Arrays.toString, так как массив не имеет переопределённого toString.

##### Задача 3. Сокращение

Текст задачи: 
Разработайте такой метод, который будет принимать список значений типа T и способ, с помощью которого список значений можно свести к одному значению типа T, которое и возвращается из метода. Используйте разработанный метод следующим образом: 1) передайте в метод список со значениями "qwerty", "asdfg", "zx" и сформируйте одну большую строку, которая состоит из всех строк исходного списка; 2) передайте в метод список со значениями 1, -3, 7 и верните сумму всех значений исходного списка; 3) имеется список, состоящий из списков целых чисел, получите общее количество элементов во всех списках (подсказка: решить задачу можно в одно действие или последовательно использовать методы из 3.3.1 и 3.3.3). Далее необходимо изменить разработанный метод таким образом, чтобы данный метод гарантированно не возвращал null и не выбрасывал ошибок в том случае, если исходный список пуст.

Алгоритм решения: 
Объявлен функциональный интерфейс Combiner<T> с единственным методом T combine(T left, T right), описывающий операцию над двумя значениями. Разработан обобщённый метод reduce с одним параметром типа: static <T> T reduce(List<T> list, T initial, Combiner<T> comb). Метод заводит аккумулятор result, равный initial, проходит по списку и на каждом шаге выполняет result = comb.combine(result, элемент), после чего возвращает аккумулятор. Начальное значение initial является нейтральным элементом (пустая строка для конкатенации, 0 для суммы) и одновременно гарантирует корректную работу на пустом списке: если список пуст, цикл не выполняется и возвращается initial, поэтому метод не возвращает null и не выбрасывает ошибок. Созданы два класса-реализации: StringConcat (конкатенация строк) и IntegerSum (сложение чисел). Третий сценарий решён в два шага: сначала методом apply из задачи 3.3.1 каждый вложенный список преобразуется в свой размер с помощью класса ListLength (реализует Function<List<Integer>, Integer> и возвращает list.size()), затем полученный список чисел сворачивается методом reduce с IntegerSum и начальным значением 0. В главном методе метод reduce вызывается трижды; для демонстрации требования о пустом списке метод также может быть вызван с пустым списком, что возвращает начальное значение.

##### Задача 4. Коллекционирование

Текст задачи: 
Разработайте такой метод, который будет возвращать коллекцию типа P со значениями типа T. Данный метод будет принимать: 1) список исходных значений; 2) способ создания результирующей коллекции; 3) способ передачи значений исходного списка в результирующую коллекцию. Используйте разработанный метод следующим образом: 1) передайте в метод список со значениями 1, -3, 7 и верните их разбитыми на два подсписка, в одном из которых будут только положительные числа, а в другом только отрицательные; 2) передайте в метод список со значениями "qwerty", "asdfg", "zx", "qw" и верните их разбитыми на подсписки таким образом, чтобы в любом подсписке были строки только одинаковой длины; 3) передайте в метод список со значениями "qwerty", "asdfg", "qwerty", "qw" и верните набор такого вида, который не может содержать одинаковые объекты.

Алгоритм решения: 
Объявлены два функциональных интерфейса: ResultFactory<R> с методом R create() (создание пустой результирующей коллекции) и ResultWriter<R, T> с методом void add(R result, T value) (передача одного значения в коллекцию). Разработан обобщённый метод collectValues с двумя параметрами типа: static <T, R> R collectValues(List<T> source, ResultFactory<R> factory, ResultWriter<R, T> writer). Метод создаёт пустую коллекцию через factory.create(), проходит по исходному списку и для каждого элемента вызывает writer.add(result, элемент), после чего возвращает коллекцию. Метод не знает, какая именно коллекция используется (список, словарь или множество) – это определяется переданными фабрикой и писателем. Созданы три пары классов-реализаций. Для первого сценария Factory1 создаёт List<List<Integer>> из двух пустых подсписков, Writer1 кладёт неотрицательное число в первый подсписок (get(0)), а отрицательное – во второй (get(1)). Для второго сценария Factory2 создаёт пустой HashMap<Integer, List<String>>, Writer2 берёт длину строки как ключ, при отсутствии ключа создаёт новый список и кладёт его в словарь, затем добавляет строку в список по ключу. Для третьего сценария Factory3 создаёт пустой HashSet<String>, Writer3 просто вызывает set.add(value) – уникальность обеспечивает само множество. В главном методе метод collectValues вызывается трижды с соответствующими фабриками и писателями, результаты выводятся на экран.
